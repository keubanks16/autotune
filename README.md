# 🎤 Karsyn & Karter's AutoTune ✨

Tap record, sing, and hear yourself come back sounding like a pop star.

**Sounds:** 🌟 Pop Star · 🤖 Robot · 🏟️ Big Stage · 👯 Choir (adds harmonies)

Everything runs in the browser: it figures out the song's key, snaps each note to pitch (PSOLA pitch-shifting keeps the voice natural), then adds studio polish — EQ, compression, doubling, reverb and echo. Save shares or downloads a WAV.

Open on iPhone → Share → **Add to Home Screen** to use it like an app.
